image-music

Colour picks the key. Lines pick the rhythm. Brightness picks the notes.

Load an image.
  • Hue walks the circle of fifths → key. Lightness → mode (bright = Lydian, dark = Phrygian). Saturation → chord richness.
  • Vertical lines cut across time → percussive hits. Horizontal run along it → pads. Diagonals → arpeggios. Texture → noise.
  • Left→right is time, bottom→top is pitch, bright cells are the notes.
